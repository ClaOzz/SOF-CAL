SOF-CAL 4.4.0 · Guía de conexión

Incorporar la lista maestra de documentos

Guardar el enlace en Ajustes no importa los documentos. El enlace identifica el Excel. Power Automate leerá la hoja LME y enviará su catálogo a SOF-CAL. Los planos siguen almacenados en SharePoint; la app abre los enlaces de la columna J.

Primero haremos una prueba manual completa. Después se programa la repetición. Esta guía no confirma una conexión ya activada.

1. Comprueba el acceso al Excel

Entra con tu cuenta Microsoft de SOFRATESA al archivo compartido por Darbet, dentro de 03. Documentos para Compartir → 2026.11.03 - Oscar LME para prueba de Aplicación. Debes poder abrirlo en Excel para la Web y editarlo. El archivo se llama D220-0000-G00-SOF-DOC-LI-0015 Lista Maestra de Documentos SOFRATESA - MDR - D220 - Oct.2026.xlsm.

La conexión de Power Automate usará una cuenta autorizada para ese archivo. Los lectores de la app no necesitan editar el Excel; para abrir cada plano sí necesitan permiso de lectura Microsoft sobre ese documento.

2. Guarda la fuente en SOF-CAL

  1. Entra como administrador.
  2. Abre Ajustes → Google y respaldo → LME y correos de alertas.
  3. Pega el enlace compartido por Darbet en el campo de LME y guarda/publica la configuración.

Usa el enlace del Excel, no el de la carpeta ni el de un PDF. No cambies la dirección del servidor Google.

3. Prepara la clave privada en Google

  1. Abre el proyecto de Apps Script que ya usa SOF-CAL.
  2. En Configuración del proyecto → Propiedades del script, agrega LME_SYNC_SECRET.
  3. Como valor, guarda una clave aleatoria de al menos 32 caracteres, creada por tu gestor de contraseñas. Si ya existe, conserva la misma.

Esta clave se copiará únicamente en las dos acciones HTTP del flujo. No es tu contraseña de Gmail. No la envíes por chat, no la subas a GitHub ni la pongas en la URL.

El proyecto debe tener el backend 4.4.0, incluido DocumentacionLME.gs y Gestion42.gs. Si aún no lo publicaste: Implementar → Administrar implementaciones → Editar → Nueva versión → Implementar, sobre la implementación existente. El número interno de implementación de Google no cambia el nombre SOF-CAL 4.4.0.

4. Crea el script de lectura en Excel

  1. Descomprime el paquete SOF-CAL. Abre SOF-CAL/power-automate/Exportar-LME.ts con un editor de texto y copia todo su contenido.
  2. En el Excel web: Automatizar → Nuevo script → Crear en el editor de código. Sustituye el código inicial por el copiado.
  3. Guárdalo como SOFCAL_Exportar_LME y pulsa Ejecutar.

Debe terminar sin error. Si indica que falta T_D220_LME o Tabla4, detente: esas son las tablas que espera el script; hay que revisar la estructura del libro antes de continuar. No renombres tablas al azar. Si no aparece Automatizar, consulta al administrador Microsoft 365 sobre la disponibilidad de Office Scripts.

5. Crea el flujo de prueba

En Power Automate, selecciona Crear → Flujo de nube instantáneo → Desencadenar un flujo manualmente. Nombre: SOF-CAL Sincronizar LME. Usa tu conexión corporativa autorizada.

6. Lee el enlace guardado por Administración

Agrega una acción HTTP y renómbrala exactamente Leer_fuente_LME. Configura:

  • Método: POST.
  • URI: la dirección de Apps Script indicada abajo.
  • Encabezado: Content-Type, valor application/json.
https://script.google.com/macros/s/AKfycbztvXUgPcnr25n9LRuLMzHjq63q091xKjOzZvU56Uqi-MD70B4LrWz3u6okdC-IPnq7/exec

Cuerpo; sustituye solamente el texto CLAVE_PRIVADA por la clave del paso 3:

{"action":"lmeSource","secret":"CLAVE_PRIVADA"}

En Configuración de la acción activa Entradas seguras y Salidas seguras. La acción HTTP puede exigir licencia Premium; si aparece ese bloqueo, hay que resolver la licencia o usar importación manual. No basta con pegar el enlace en otro conector.

7. Localiza el archivo en SharePoint

Agrega SharePoint → Obtener metadatos de archivo usando la ruta de acceso. Renombra la acción Archivo_LME. En cada campo selecciona Introducir valor personalizado → Expresión y pega lo correspondiente:

Dirección del sitio:

body('Leer_fuente_LME')?['data']?['site']

Ruta del archivo:

body('Leer_fuente_LME')?['data']?['path']

Así toma el enlace configurado en la app. Aunque sea un OneDrive empresarial, la fuente actual pertenece al sitio personal de Darbet en SharePoint. Si responde 403, la cuenta de la conexión no tiene acceso suficiente; si responde 404, revisa el enlace y la ruta devuelta.

8. Ejecuta el script sobre ese archivo

Agrega Excel Online (Business) → Ejecutar script y renombra la acción Exportar_LME.

  • Ubicación: el sitio personal de Darbet. Usa el mismo sitio del paso 7 mediante valor personalizado si el conector lo admite.
  • Biblioteca de documentos: la biblioteca Documents/Documentos de ese sitio, la que contiene la carpeta compartida.
  • Archivo: contenido dinámico Identificador de Archivo_LME, no el enlace del navegador.
  • Script: SOFCAL_Exportar_LME, guardado en el paso 4.

Si la ubicación o biblioteca no admite valores dinámicos, selecciónala manualmente. Cuando se cambie la LME a otro sitio o biblioteca habrá que actualizar también estos selectores; cambiar solo la ruta dentro del mismo sitio sí lo resuelve el paso 7. Un archivo .xlsm puede usarse con Ejecutar script, pero Power Automate no ejecuta sus macros VBA ni este script refresca Power Query.

9. Envía el catálogo a SOF-CAL

Agrega otra acción HTTP, llamada Enviar_LME, con POST, la misma URI y el mismo encabezado que el paso 6. Cuerpo:

{
  "action": "lmeSync",
  "secret": "CLAVE_PRIVADA",
  "sourceRevision": "@{body('Leer_fuente_LME')?['data']?['revision']}",
  "payload": "@{body('Exportar_LME')?['result']}"
}

Reemplaza CLAVE_PRIVADA. El diseñador debe interpretar las dos expresiones como contenido dinámico; si no lo hace, insértalas desde la pestaña Expresión: la revisión viene de Leer_fuente_LME y result de Exportar_LME. No pegues el Excel completo ni su enlace en payload.

Activa Entradas seguras y Salidas seguras en ambas acciones HTTP. Si Google devuelve una redirección, comprueba que la acción llegue a la respuesta JSON final. Un estado HTTP 200 por sí solo no significa que la importación fue aceptada.

10. Prueba y verifica

  1. Guarda el flujo. Pulsa Probar → Manualmente → Ejecutar flujo.
  2. Agrega una acción Componer después de Enviar_LME con la expresión siguiente: mostrará solo el resultado, sin revelar el secreto.
body('Enviar_LME')

El resultado esperado es ok: true y, dentro de data, saved con un número de documentos y syncedAt con la fecha. Si aparece ok:false, lee error y corrige ese paso antes de programar el flujo.

  1. En SOF-CAL abre Documentación → Actualizar.
  2. Busca un código conocido. Comprueba título, revisión y estado; pulsa Consultar y verifica que abra el plano correcto.
  3. Comprueba también un registro sin enlace. El aviso a Darbet se envía solo cuando alguien pulsa Reportar enlace faltante y confirma; no se envía por esta sincronización.

11. Programa la actualización

Una vez que la prueba funcione, crea un flujo de nube programado con Recurrencia cada 30 minutos y las mismas cinco acciones: Leer_fuente_LME, Archivo_LME, Exportar_LME, Enviar_LME y Componer. Configura concurrencia 1. Mantén el flujo manual para pruebas, sin ejecutarlo a la vez que el programado.

La actualización es periódica. Los enlaces del Excel deben estar actualizados antes de la ejecución. Si se cambia de archivo o de tablas, vuelve a hacer la prueba del paso 10.

Qué conexión queda preparada

Este flujo lee Excel y actualiza el catálogo de documentación de SOF-CAL. No modifica el Excel desde la app, no sincroniza equipos o FNC/FHC y no concede acceso a los planos. Esas conexiones son independientes.

Si se bloquea un paso, comparte su nombre y el mensaje de error ocultando la clave. No desactives Entradas seguras para tomar una captura.

Referencia oficial: Microsoft — archivos .xlsm en Power Automate. Instrucciones basadas en los archivos de SOF-CAL 4.4.0; la disponibilidad de acciones depende del entorno Microsoft 365.
